# Німецька з турботою для Ані

Інтерактивний навчальний посібник з німецької мови, створений з любов'ю та турботою. 
Проєкт побудований на принципах **SOLID** та чистій архітектурі, що дозволяє легко розширювати контент без великих змін у коді.

## 🚀 Як запустити локально

Проєкт НЕЕЕЕЕ потребує збірки (Node.js, Webpack, Vite тощо). Все працює на чистих ES-модулях.

1. Склонуй репозиторій або завантаж файли.
2. Відкрий термінал у папці проєкту.
3. Запусти будь-який локальний сервер (наприклад, через Python або розширення Live Server у VS Code):
   ```bash
   python -m http.server 8000
   ```
4. Відкрий у браузері `http://localhost:8000`.

*(Увага: відкриття `index.html` подвійним кліком через `file://` не працюватиме через політику CORS для ES-модулів).*

## 📂 Структура проєкту

```text
├── index.html              # Єдина точка входу (підключає main.js)
├── styles/

├── src/
│   ├── main.js             # Ініціалізація застосунку
│   ├── app/                # Ядро застосунку (Стан, Роутинг, Оркестрація)
│   │   ├── App.js

│   │   └── State.js
│   ├── domain/             # Моделі даних (Бізнес-логіка)

│   │   └── Exercise.js
│   ├── ui/                 # Відображення та взаємодія
│   │   ├── renderers.js    # Чисті функції рендеру HTML

```

## 🛠️ Як додати новий контент (Без змін у коді)

Завдяки архітектурі, тобі **не потрібно чіпати логіку** (`App.js`, `Router.js` тощо), щоб додати нові сторінки чи рівні.

### Додати нову сторінку до існуючого рівня
1. Відкрий файл потрібного рівня, наприклад `src/content/levels/level1.js`.
2. Знайди масив `pages`.
3. Додай новий об'єкт за зразком існуючих:
```javascript
{
  id: "1-7",
  title: "Нова сторінка",
  subtitle: "Підзаголовок",
  blocks: [
    { heading: "Заголовок блоку", text: "Текст..." },
    { heading: "Приклади", examples: [{ de: "Deutsch", ua: "Німецька", tip: "Порада" }] }
  ]
}
```

### Додати новий рівень
1. Створи файл `src/content/levels/level3.js` (скопіюй структуру з `level1.js`).
2. Відкрий `src/content/levels/index.js`.
3. Імпортуй новий рівень та додай його в масив `levels`:
```javascript
import { level3 } from './level3.js';

export const levels = [
  level1,
  level2,
  level3, // <-- Додано
  // ...
];
```

### Додати словникове слово
1. Відкрий `src/content/dictionary.js`.
2. У масиві `vocabTables` знайди потрібну таблицю (наприклад, "Дієслова").
3. Додай новий рядок у `rows`:
```javascript
{ term: "machen", translation: "робити", exampleDe: "Ich mache das.", exampleUa: "Я роблю це." }
```

### Додати інтерактивну вправу
1. У файлі сторінки додай масив `exercises`:
```javascript
exercises: [
  {
    id: "ex-1",
    question: "Обери правильний варіант:",
    options: [
      { text: "Правильний", correct: true },
      { text: "Неправильний", correct: false }
    ]
  }
]
```

## 🛡️ Безпека та якість
- **XSS-захист:** Усі текстові дані екрануються через `escapeHtml()` перед вставкою в DOM.
- **Event Delegation:** Замість `onclick` у HTML використовується `data-action` та делегування подій. Це дозволяє уникнути проблем із динамічним рендером.
- **Розділення відповідальності:** Логіка, рендер та дані повністю розділені.
